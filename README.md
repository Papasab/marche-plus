# 🛍 Marché+ — Boutique en ligne

## 🚀 Lancer le projet

```bash
npm install
npm run dev
```

Ouvrir : http://localhost:5173

## 📸 Ajouter des photos de produits

Mettez vos photos dans le dossier `public/images/` avec ces noms :
- sac-dos.jpg
- casque.jpg
- lampe.jpg
- montre.jpg
- chaussures.jpg
- carnet.jpg
- thermos.jpg
- clavier.jpg
- lunettes.jpg
- plante.jpg
- stylo.jpg
- chargeur.jpg

## 🌐 Mettre en ligne sur Netlify

```bash
npm run build
```

Glissez le dossier `dist` sur netlify.com

## ✨ Fonctionnalités
- Boutique avec photos réelles
- Panier + paiement en 3 étapes
- Notification WhatsApp automatique
- Commandes sauvegardées dans Supabase
- Tableau de bord admin
